0.6.0-beta.1 安卓通用安装模板：
- CooDock-0.6.0-beta.1-companion-debug.apk：连接远端主线，包含世界聊天与设备能力桥。
- CooDock-0.6.0-beta.1-workbench-debug.apk：另含可选本机 Core/World 运行时与共同记忆适配。
两者同包名 `net.tina.coodock`、同签名、versionCode 54。请保留原数据覆盖安装。设备授权仍由安卓系统处理。
读屏/相机默认由 World 按需取帧；旧观察通道可在连接页选择。World 运行、模型运行和连接可达分别报告。
iOS 本轮没有新构建；原 0.2.2 测试材料继续保留。

通用模板不带个人凭据。启用 World 后，可从主机的 World 总览卡片生成公网或直连专属包；苹果 IPA 可尝试使用 AltStore Classic 自行签名。详见上一层 README。
